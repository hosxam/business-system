## How to Use These Files Daily

### Morning routine (10 min)

```
1. Open OPERATING_SYSTEM.md
   → Read "Today's Priority Order"
   → Check "What to Post Today"
   → Check "What to Comment Today"
   → Check "What to Check Today"

2. Open COPY_PASTE_DRAFTS.md
   → Find today's LinkedIn draft
   → Find Facebook comments (3-5)
   → Copy and paste to each platform

3. Open APPROVAL_QUEUE.md (if needed)
   → Check if drafts need your approval before posting
```

### Evening routine (5 min)

```
1. Open GROWTH_DASHBOARD.md
   → Find today's date in Daily Metrics Tracker
   → Fill in numbers

2. git commit the changes

3. Look at tomorrow's actions in 7_DAY_EXECUTION_BOARD.md
```

### Weekly routine (15 min on Sunday)

```
1. Open WEEKLY_REVIEW_TEMPLATE.md
2. Fill in all metrics
3. Answer the 10 review questions
4. Apply decision rules
5. Plan next week's experiment
6. Commit the review
```

## What Must Stay Manual

| Action | Why |
|--------|-----|
| Posting LinkedIn content | Each post needs manual formatting, UTM insertion, and timing |
| Facebook comments | Must be relevant to the specific thread — no copy-paste same comment everywhere |
| Reddit posting | Account needs careful warm-up — one mistake destroys the account |
| Clinic email sending | Each email needs recipient review and personalization |
| Ko-fi product updates | No API for programmatic editing |
| Checking analytics | Dashboard metrics need human judgment |
| Weekly review | Requires qualitative assessment of what worked |
| Response handling | Replying to comments/questions needs real judgment |
