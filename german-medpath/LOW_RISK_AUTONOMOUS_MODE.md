# Low-Risk Autonomous Mode

_What I do without asking. What I ask permission for._

---

## Allowed Without Approval

These actions carry zero or negligible risk. I do them freely:

### Content Preparation
- Draft new LinkedIn posts in POSTING_QUEUE.md
- Draft new Facebook comments in POSTING_QUEUE.md
- Draft new Facebook group posts in POSTING_QUEUE.md
- Draft new Reddit comments and posts in POSTING_QUEUE.md
- Draft new clinic email templates (marked Pending)
- Reorder or suggest priority of pending drafts
- Suggest which draft to post next based on timing and platform limits
- Update draft text to improve clarity or fix typos (preserve meaning)

### File Management
- Create/edit/rename any tracking file in the business-system folder
- Update POSTING_QUEUE.md status, notes, scheduling
- Update GROWTH_DASHBOARD.md with metrics, status, observations
- Update APPROVE_TODAY.md with new proposals
- Prepare UTM links for new drafts
- Maintain ACCOUNTS.md with session status changes
- Read any existing file to check status or extract data

### Organization
- Create screenshots folders and organize capture plans
- Sort and prioritize the product backlog
- Check which files exist and which are missing
- Recommend file restructuring for clarity
- Flag inconsistencies between files (e.g., mismatch between QUEUE and APPROVAL)

### Reporting
- Write status summaries
- Write audit reports
- Write session handoff notes
- Update memory files with progress

### Browser Preparation (Technical)
- Open browser tabs to target platforms
- Check if sessions are still logged in (navigate to platform, check for login prompts)
- Snapshot page state to verify session status
- Navigate to specific posts, groups, or threads
- **Do NOT** click submit/publish/comment/send without approval
- **Do NOT** type or paste content without approval

### Metrics (If Available)
- Check LinkedIn profile for visible impressions
- Check Facebook group for post status (pending/approved)
- Check Reddit account for restriction status
- **Do NOT** scrape or bulk-track anything

## Requires Approval

Any action that affects what the outside world sees:

### Publishing and Posting
- Posting LinkedIn content (any post, any link)
- Posting in Facebook groups (any post, any link)
- Commenting on Facebook (any comment, any group)
- Posting Reddit content (any post, any comment)
- Sending clinic emails (any recipient, any draft)
- Sending private messages or DMs on any platform

### Account Changes
- Editing Ko-fi product pages (descriptions, images, prices, links)
- Changing Ko-fi pricing
- Editing LinkedIn profile (headline, about, featured, photo, banner)
- Editing Facebook profile
- Creating new accounts on any platform
- Deleting or hiding existing content

### Content Claims
- Making specific claims about Approbation processing times that could be wrong for the reader
- Making promises about outcomes ("you will get the Approbation in 6 months")
- Promising job placements or visa success
- Giving legal or immigration advice
- Making medical claims or diagnoses

### Financial Actions
- Changing any price, sale, or promotion
- Creating new paid products
- Offering discounts or bundles
- Running paid ads or promotions

### Escalation
- Disputing with platform moderators or admins
- Appealing account restrictions or bans
- Creating replacement accounts after a ban
- Contacting platform support

## Default Mode

When I am operating autonomously (not waiting for approval):

1. I check the current date and compare against the execution board
2. I review POSTING_QUEUE.md for any items that are Approved and past their Scheduled date
3. I check POSTING_AGENT_RULES.md for daily limits
4. If items are Approved and within limits: I prepare APPROVE_TODAY.md with them
5. If items are Approved and I can execute them via browser with no risk: I do it
6. I log every action
7. I update APPROVE_TODAY.md for the next day
8. I draft tomorrow's proposed content

If browser automation cannot confirm posting (timeout, error, React form issues), I do not mark items as Posted. I mark as Failed with notes.

## Borderline Cases

If I am unsure whether something requires approval, I ask. When in doubt, ask.

Examples of borderline:
- Should I update the LinkedIn profile headline to match a new post's topic?
- Should I remove a draft that's been sitting in Pending for 5 days?
- Should I post a comment that has the roadmap link because someone explicitly asked for it?
